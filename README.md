# Quote Generator

A small vanilla HTML/CSS/JS project that displays a random quote each time you click a button.

## Run it

Just open `index.html` in your browser, or use a live server extension in VS Code.

## Files

- `index.html` — page structure
- `style.css` — styling
- `script.js` — quote data and logic
